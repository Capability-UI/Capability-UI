# Capability UI Protocol specification

The complete specification is included as a standalone HTML artifact:

[Open the full CUP specification in the repository](https://github.com/Capability-UI/Capability-UI/blob/main/specification/index.html)

The repository copy lives at [`specification/index.html`](https://github.com/Capability-UI/Capability-UI/blob/main/specification/index.html). It includes the protocol model, lifecycle examples, MCP profile, external-agent model, security rules, SQL persistence guidance, and the explanatory article.

Use the executable TypeScript tests in `test/` to verify implementation behavior. The HTML specification describes the intended protocol contract; the package source and tests show the currently executable behavior.
